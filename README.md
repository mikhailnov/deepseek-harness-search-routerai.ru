# Веб-поиск RouterAI для DeepSeek Harness

Плагин подключает к DeepSeek Harness поиск в интернете через сервис
[RouterAI.ru](https://routerai.ru/p/9WAUCXCP). Модель получает штатный инструмент
`web_search` и может сама искать актуальные сведения: курсы валют, новости,
документацию — и всё, что появилось после её обучения.

Плагину не важно, через какого провайдера идёт основная работа модели.
Он одинаково подходит, когда все запросы DeepSeek Harness отправляются
через RouterAI, и когда основной провайдер другой — например, Z.AI, —
а нужен настраиваемый поиск с выбором модели и движка. Без плагина
штатный поиск работает только в конфигурации DeepSeek; плагин закрывает
этот пробел для остальных провайдеров.

Для работы нужен API-ключ [RouterAI.ru](https://routerai.ru/p/9WAUCXCP)
(регистрация и личный кабинет). Поиск платный: деньги списываются с баланса
RouterAI, обычно от 0,5 до 3 ₽ за запрос в зависимости от модели и движка.

## Как начать

1. Получите API-ключ в личном кабинете [RouterAI.ru](https://routerai.ru/p/9WAUCXCP)
2. Откройте в DeepSeek Harness страницу **Plugins** и выберите карточку
   **Веб-поиск RouterAI** в разделе **Built-in plugin settings** (рядом
   с Subagent и Agent loop) — откроется страница с настройками. Второй путь
   к той же форме: карточка в разделе **Installed plugins** → блок
   **Components** → строка **Веб-поиск RouterAI**.
3. Вставьте ключ в поле «API-ключ RouterAI» и нажмите «Сохранить».
   Настраивать больше ничего не нужно: параметры по умолчанию подобраны
   для дешёвого и быстрого поиска.
4. Проверьте: в новом сеансе спросите модель, например: «Какой сегодня курс
   доллара по данным ЦБ РФ? Используй поиск». Модель вызовет `web_search`
   и ответит со ссылками на источники.

Пока ключ не задан, инструмент `web_search` модели не предлагается; после
сохранения ключа он появляется в следующем шаге модели — перезапускать ничего
не нужно.

## Как это работает

Запрос уходит в RouterAI (API совместим с OpenAI), к которому подключается
веб-поиск: RouterAI находит страницы, а выбранная модель собирает по ним
краткий ответ со ссылками на источники. DeepSeek Harness получает этот ответ
как обычный результат `web_search` и показывает его модели вместе с адресами
источников.

Технически: плагин регистрирует провайдера `routerai` в службе `ctx.web`
(`ctx.web.registerSearchProvider`), поэтому работает штатный инструмент
`web_search`. Один запрос — один вызов `POST /chat/completions` с плагином
RouterAI `web`; текст ответа и аннотации `url_citation` нормализуются в
`WebSearchResult` (ответ + источники с заголовками и выдержками). Ключ
хранится в настройках профиля и передаётся только на настроенный адрес;
переадресация запросов отключена, чтобы ключ не ушёл на другой сервер.

## Модели и движки

Поисковый движок выбирается в настройках:

| Движок | Описание |
|--------|----------|
| `auto` | RouterAI сам выбирает подходящий движок (рекомендуется) |
| `native` | собственный поиск провайдера модели (OpenAI, Google, xAI, Anthropic) |
| `exa` | поиск Exa; работает с любой моделью, примерно 0,45 ₽ за результат |

Список моделей в настройках содержит только модели, проверенные с веб-поиском
RouterAI (18 ноября 2026 года). Дешёвые варианты:

- `yandex/aliceai-llm-flash` — самая дешёвая (около 0,05 ₽ за запрос),
  отвечает конспектом без ссылок на источники;
- `qwen/qwen3.5-9b` или `openai/gpt-5-nano` с движком `exa` — примерно 2,3 ₽
  за запрос при 5 результатах, со ссылками;
- `x-ai/grok-4.20` с движком `native` — около 0,5 ₽ за поисковый запрос;
- `google/gemini-2.5-flash-lite` — дешёвый поиск Google со ссылками.

Подробнее о поисковых движках — в [документации веб-поиска RouterAI](
https://routerai.ru/docs/guides/overview/plugins/web-search?ref=9WAUCXCP).

Движок `native` поддерживают не все модели: при ошибке «does not support
native web search» переключите движок на `auto` или `exa`. Качество и вид
ответа зависят от модели: например, Claude Haiku отвечает текстом без
ссылок, а Gemini и GPT дают ссылки.

## Настройки

Все параметры меняются на странице настроек и применяются без перезапуска.

| Поле | Назначение |
|------|-----------|
| API-ключ RouterAI | ключ из личного кабинета; без него поиск неактивен |
| Модель поиска | модель, которой RouterAI выполняет поиск и сводит результаты |
| Движок поиска | `auto`, `native` или `exa` |
| Базовый URL API | меняйте только для совместимого прокси; пустое поле возвращает значение по умолчанию |
| Максимум результатов | от 1 до 20; при движке `exa` оплата идёт за каждый результат |
| Лимит токенов ответа | слишком малый лимит у рассуждающих моделей оставляет ответ пустым |
| Таймаут запроса | действует меньшее из этого значения и ограничения инструмента `web_search` (60 с) |
| Промпт для поиска | необязательное уточнение для поисковых запросов, например «Ищи актуальные и достоверные источники» |
| Только домены / Исключить домены | ограничение поиска конкретными сайтами; поддерживается не всеми движками |

## Совместимость и ограничения

- Плагин проверен с DSH 0.2.2-rc.3; заявлена совместимость с 0.2.2-rc.3 и
  новее (`engines.dsh`). Используется только регистрация провайдера
  `ctx.web.registerSearchProvider` и страница настроек в слоте
  `plugins.row.config`.
- Патч бандла закрепляет провайдер `routerai` в службе web. Если это
  не нужно, удалите строку `web` из `cordis.patch.yml` и выберите провайдера
  «RouterAI» на странице «Web search and fetch» в настройках Harness.
- Ответ и ссылки готовит выбранная модель: точность данных стоит проверять
  по первоисточникам.
- Параметры доменных фильтров поддерживаются не всеми движками (у Anthropic
  они взаимоисключающие).
- Секрет (API-ключ) не отображается в форме: поле сообщает, задан ли ключ,
  но не раскрывает его.

## Установка и удаление

Установка: **Plugins → Add plugin** → указать каталог этого плагина (или
`dsh plugin --profile <имя> add <путь>`). Удаление — кнопка **Uninstall**
на странице плагина.

При обновлении с версии до ноября 2026 года, где строка патча имела
id `web-search-routerai`: удалите из `cordis.patch.yml` профиля старую
строку с этим id и перенесите её `config` (включая ключ) в новую строку
`id: '@local/dsh-web-search-routerai'` — иначе ключ «потеряется»
и плагин загрузится дважды.

## Известные ограничения

- Карточка настроек появляется в разделе **Built-in plugin settings**
  вместе со встроенными плагинами: это единственное место, где страница
  Plugins размещает карточки настроек. После крупных обновлений DeepSeek
  Harness раздел стоит проверить первым.
