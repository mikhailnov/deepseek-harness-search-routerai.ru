# Веб-поиск RouterAI

Плагин подключает **веб-поиск через [RouterAI](https://routerai.ru)** к DeepSeek
Harness: модель получает работающий инструмент `web_search`, даже когда harness
работает не через DeepSeek, а через любого провайдера LLM (например, Z.AI).

Работает через официальный плагин RouterAI `web`: запрос уходит в
`POST /api/v1/chat/completions` с параметром `plugins`, ответ модели и её
цитаты `url_citation` нормализуются в источник `web_search` (текст ответа +
список источников с URL, заголовками и выдержками).

## Настройка

1. Получите API-ключ в личном кабинете RouterAI: **routerai.ru → Ключи**.
2. Откройте **Plugins → Web search RouterAI → Настроить** и вставьте ключ в
   поле «API-ключ RouterAI».
3. При необходимости выберите модель и движок поиска (см. ниже).

Без ключа провайдер неактивен и инструмент `web_search` модели не
предлагается; после сохранения ключа он появляется в следующем шаге модели.

## Модели и движки

Движок выбирается в настройках плагина:

| Движок | Описание |
|--------|----------|
| `auto` | RouterAI сам выбирает движок (рекомендуется) |
| `native` | нативный поиск провайдера модели (OpenAI, Google, xAI, Anthropic) |
| `exa` | поиск Exa, работает с любой моделью |

Список моделей в настройках содержит только модели, проверенные с веб-поиском
RouterAI (18 ноября 2026). Самые дешёвые связки:

- `qwen/qwen3.5-9b` / `openai/gpt-5-nano` + движок `exa` — примерно 2,3 ₽ за
  запрос при 5 результатах;
- `google/gemini-2.5-flash-lite` + `native` — дешёвый нативный поиск Google;
- `x-ai/grok-4.20` + `native` — примерно 0,53 ₽ за поисковый запрос.

Движок `native` поддерживают не все модели: при ошибке «does not support
native web search» переключите движок на `auto` или `exa`.

## Совместимость

Использует только регистрацию провайдера `ctx.web.registerSearchProvider` и
пакет `@deepseek-ai/schemastery`; совместим с DSH ≥ 0.2 (проверено на
0.2.2-rc.3). Патч бандла закрепляет `searchProvider: routerai` в службе web —
если закрепление не нужно, уберите строку `web` из `cordis.patch.yml` и
выберите провайдера «RouterAI» в настройках веб-поиска DSH.

## Ограничения

- Ответ и цитаты генерирует выбранная модель: качество и наличие цитат
  зависят от модели (например, Claude Haiku отвечает текстом без аннотаций).
- Параметры `include_domains` / `exclude_domains` поддерживаются не всеми
  движками (у Anthropic они взаимоисключающиеся).
- Таймаут запроса действует вместе с ограничением инструмента `web_search`
  (60 с в базовой композиции DSH): срабатывает меньшее из двух значений.
